# 排版乱码硬闸（gzh-design / 2号排版共用）

## 根因（已核实）
1. 文本节点写成字面量 `&quot;`（浏览器成功稿应为真正 `"`）
2. Markdown 反引号 `` ` `` 漏进正文 HTML
3. `linear-` / `radial-` / `conic-gradient` 过多 → 微信结构/版式乱（validate 仅 WARNING，旧 pack 不消毒）

## 闸位置（焊死）
| 步骤 | 工具 | 行为 |
|------|------|------|
| 消毒 | `tools/gzh_design_sanitize.py` → `sanitize` | 标签外 `&quot;`/`&amp;quot;`→`"`；去文本反引号；内联 `background(-image):*-gradient(...)`→`background:#FCA5A5` |
| 门禁 | 同文件 → `gate` | 消毒后仍有文本 `&quot;`、反引号、任何 `*-gradient` → **ERROR** |
| 打包 | `tools/gzh_design_pack_bundle.py` | 抽 section 后**强制** sanitize → gate；有 ERROR 则 `sys.exit(1)` 拒绝打包；旁路写 `--html` 同目录 `*.sanitized.html`，`article.json` 用消毒后 HTML |

`validate_gzh_html.py` 对 gradient 仍可能只 WARNING；**以本硬闸 ERROR 为准**，不可只靠 validate 绿灯就推箱。

## 推箱前必跑
```bash
HTML=build_gzh_design/某篇_排版_红白色系\(red-white\).html
WS=素材/某篇工作台

python3 /workspace/gzh-skill/v2/tools/gzh_design_sanitize.py "$HTML" --write
# 或直接 pack（内部已强制 sanitize+gate）:
python3 /workspace/gzh-skill/v2/tools/gzh_design_pack_bundle.py "$WS" --html "$HTML"
# 再 publish update/add；最后:
python3 …/publish_remote_….py get --media-id … --text
# 确认 quot/bt/grad = 0
```

## 禁止
- 手改 HTML 后跳过 `pack` 直接上传旧 bundle / 脏 `preview_*_src.html`
- 把 `preview_375_src.html` 当正文源（常未同步，易误判「又乱码」）
- 为「有改动」把已干净稿改坏；主题套装禁止换摸鱼绿等（2号固定红白）

## 本地坑
同目录 `preview_375_src.html` / 旧预览若仍含 `&quot;`、反引号、gradient，**以正式 `*_排版_红白色系(red-white).html` 与 bundle/article.json 为准**。预览需从正式 HTML 重生成或覆盖。
